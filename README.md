# Roy Nyamiaka: CV site for employers

This folder is the CV site at **https://ngareroy.github.io/**: profile, CV (with PDF), skills, experience, projects, education and a contact form for job and interview invitations. It shows no rates, prices or quote requests. Those are on the freelance site at **https://ngareroy.github.io/roy-portfolio/**.

## How it stays up to date

You don't edit this site directly. It reads its content from the freelance site, so anything you save in the editor (`/roy-portfolio/admin.html`) shows here too, usually within a minute or two. It keeps its own copy of the content as a backup, in case the freelance site can't be reached.

## Changing the code or design

This folder is built from the source project (`roy-portfolio-source`). Run `/publish-site` in Claude Code. It builds both sites, exports this one into the `site-cv/` folder (a clone of this repository) and pushes both, with your OK.
